# ISP-lab

Lab work for the ISP course (information security / cryptography). Each lab
lives in its own folder under `labs/`, together with its assignment PDF, the
provided input data and any notes.

## Structure

```
labs/
  lab01/  ...  lab10/
    README.md          — task summary, how to run, notes
    ISP_L*.pdf         — assignment brief
    variantai/         — per-variant input data (where provided)
    *_helpers.py       — helper code provided with the assignment
```
